# 🧪 Предсказатель свойств материалов по формуле

Проект по машинному обучению, который предсказывает некоторые свойства материалов по их химической формуле

---

## 📁 Использовано в проекте:
- **Языки** - Python, HTML, CSS, JS
- **Библиотеки** - pandas, numpy, joblib, mp-api, scikit-learn, matplotlib, matminer, flask, pymatgen
---

## 🚀 Запуск сайта

1. **Скопируйте репозиторий**

```bash
git clone https://github.com/Fonarik1337/Chemical_Predictor
cd Chemical_Predictor
````

2. **Установите необходимые библиотеки**

```bash
pip install -r requirements.txt
````

3. **Запустите app.py**

```bash
python app.py
````
4. **Откройте предсказатель в браузере**

```bash
http://127.0.0.1:5000/
```
